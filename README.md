# MULTIDownload (2026/02/11)

MULTIDownload 是一款基於 [yt-dlp](https://github.com/yt-dlp/yt-dlp) 開發的現代化桌面下載工具，結合了 [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) 打造的美觀介面，專為解決複雜指令操作而生。

## 核心特色

### 拖曳添加

- **拖曳新增**：支援直接將網址從瀏覽器或文字編輯器拖曳至視窗任意位置。
- **智慧解析**：放開後自動填入網址並觸發分析，支援自動修補網址格式 (如 `youtube.com` -> `https://youtube.com`)，操作更流暢。

### 智慧核心管理

- **自動安裝**：首次執行時若偵測不到 `yt-dlp` 核心，程式會自動引導您下載。
- **雙重來源保障**：安裝過程優先連接 **PyPI** (快速)，若失敗會自動切換至 **GitHub Releases** (備援)，確保下載 100% 成功。
- **視覺化進度**：詳細的進度彈窗，讓您清楚掌握下載狀態。
- **Hot-fix**：核心程式與主程式分離 (位於 `lib/` 目錄)，即使 YouTube 改版，您也能在設定頁面單獨更新核心，無需重新下載整套軟體。

### 應用程式熱更新

- **熱更新**：支援透過 GitHub Release 直接推送更新。
- **全量更新**：支援下載更新包 (.zip) 並自動執行全資料夾覆蓋更新。

### 智慧歌單管理

- **整張下載 / 單曲選取**：貼上播放清單網址後，程式會自動分析並提示。
- **視覺化選單**：分析完成後按下「加入任務」，即彈出互動視窗，列出所有歌曲讓您勾選。
- **任務展開**：選取的歌曲會自動展開為個別任務加入「等待列表」。

### 搜尋功能

- **關鍵字搜尋**: 直接在主介面輸入關鍵字，程式即會自動執行雙平台搜尋 (YouTube + Bilibili)。
- **一鍵分析**: 於搜尋結果視窗中點選影片，自動填入並開始分析，操作直覺。
- **自訂數量**: 設定頁面可自訂各平台的搜尋上限。

### 字幕系統

- **多語系支援**：不只下載預設字幕，還能同時勾選多種語言（如繁中、英文、日文）。
- **智慧排序**：自動依據優先權（繁中 > 簡中 > 英文...）排序字幕軌道。
- **Embed Subs**：支援將字幕內嵌至 MP4 檔案中 (部分播放器支援切換) 或是單獨下載 `.srt` 檔。

### 自定義下載選項

- **智慧畫質選擇**：自動選取最佳畫質與編碼 (最高支援 8K / AV1 / VP9)。
- **高相容模式**：可指定下載 H.264 編碼影片，確保在舊款車機、電視或手機上完美播放。
- **會員限定存取**：支援三種 Cookie 授權模式 (瀏覽器讀取 / cookies.txt / 直接貼上)，下載 YouTube Premium 或會員限定影片。

### SponsorBlock

- **智慧去廣告**：整合 SponsorBlock 資料庫，能自動跳過影片中的廠商業配。
- **高度客製化**：提供詳細的過濾選單，您可以自由決定要移除哪些片段：
  - **贊助商/自我推銷**：還給您純淨的內容。
  - **片頭/片尾**：追劇神器，自動跳過重複片段。
  - **MV 模式**：專為聽歌打造，自動去除 MV 中間的對話與演戲橋段。

### 跨平台硬體加速

- **全面支援**：支援 NVIDIA (NVENC)、Intel (QSV) 與 AMD (AMF) 顯卡加速。
- **Mac 專屬優化**：新增 **Apple VideoToolbox** 支援，完美發揮 M1/M2/M3 晶片效能。
- **效能釋放**：將轉檔負載從 CPU 轉移至 GPU，讓您在下載同時也能流暢使用電腦。

### 智慧設定記憶

- **自動儲存**：無需手動存檔，程式會自動記憶您的下載路徑、User Agent、Cookie 模式與最大同時下載數。
- **Proxy 記憶**：可選擇記憶 Proxy 設定，方便需透過代理伺服器連線的用戶。
- **過濾偏好**：SponsorBlock 的勾選狀態也會被完整保留。
- **內建更新日誌**：直接於「關於」頁面查看版本變更，無需尋找外部檔案，更新資訊隨手可得。

### 提升設定體驗

- **直覺化管理**：全新的清單式設定介面，輕鬆管理剪貼簿監聽、通知系統、自動下載等偏好。
- **可視化狀態**：硬體加速狀態直接顯示於首頁，是否啟用 GPU 加速一目了然。
- **視窗置頂**：支援「視窗最上層顯示」模式，方便多視窗作業。
- **主題一致**：所有選單與元件皆完美適應深色/淺色模式，提供最佳視覺體驗。
- **一鍵重置**：**基本設定**頁面右上角提供「參數重置」按鈕 (⟲)，可快速將所有下載參數與輸入框恢復為預設值，輕鬆開始新任務。

## 安裝與使用

### 一般使用者 (推薦)

1. 下載最新發布的 **MULTIDownload.zip**。
2. 解壓縮至任意資料夾 (內含 FFmpeg，無需額外安裝)。
3. 雙擊 `MULTIDownload.exe` 即可使用。
4. **首次執行**：若程式提示缺少核心，請點擊「確定」，程式將自動為您下載安裝。

## 操作指南

### 步驟一：基本設定

1. 在 **[影片網址]** 欄位貼上連結。
2. 點擊 **[分析網址]** 按鈕。
   - 程式會抓取影片標題、封面以及可用的字幕列表。
   - **若是歌單**：分析後會提示您設定格式，接著請按「加入任務」來選歌。
3. 設定 **[下載位置]** (預設為當前目錄)。
4. 如需下載會員/年齡限制影片，請於 [進階選項] > [帳號授權與 Cookie] 選擇「瀏覽器」、「檔案」或「貼上」模式。

### 步驟二：選擇格式

- 前往 **[格式/畫質]** 分頁。
- **懶人模式 (推薦)**：
  - 直接開啟 **「相容性最佳」** 開關。
  - 程式會自動設定為最通用的格式 (影片: H.264+AAC / 音訊: MP3)，確保車機與舊電視能完美播放。
- **進階模式**：
  - 保持「相容性最佳」關閉。
  - 自由選擇最高畫質 (8K/4K)、視訊編碼 (AV1/VP9) 與音訊格式 (FLAC/M4A)。

### 步驟三：開始下載

- **快速下載**：點擊下方 **[快速下載]** 按鈕，任務將立即開始執行。
- **排程下載 (推薦)**：
  1. 點擊 **[加入任務]**，任務將加入 **[任務列表]** 的「等待下載」清單 (暫停狀態)。
  2. 此時您可以繼續新增多個任務。
  3. 前往 **[任務列表]** 頁籤，勾選您要下載的項目，最後點擊 **[開始選取項]**。

## 常見問題 (FAQ)

**Q: 按下「安裝核心」後會發生什麼？**
A: 程式會開啟一個進度視窗，自動連接 PyPI 下載最新版 yt-dlp。如果 PyPI 連線失敗，會自動切換到 GitHub 下載。安裝完成後，程式會自動建立 `lib` 資料夾並放入核心檔案。

**Q: 下載的影片在車上播放沒有聲音？**
A: 這通常是因為影片使用了 Opus 音訊編碼。請在格式設定中勾選 **「H.264 (相容模式)」**，即可解決此問題。

**Q: 開啟 SponsorBlock 卻還是有廣告出現？**
A: SponsorBlock 的資料庫中沒有紀錄該影片的廣告節點，因此無法移除廣告片段。

**Q: 如何下載會員/年齡限制影片？**
A:
在[進階選項]中更改cookies設定：

- 請在瀏覽器上登入 YouTube 帳號，並勾選對應的瀏覽器 (例如 Chrome)。
- 貼上 cookies。
- 導入cookies.txt檔案。

**Q: 若出現 unable to download video data: HTTP Error 403: Forbidden？**
A: 此錯誤為 YouTube 阻擋伺服器連結，請先使用以下方法排除問題：

- 更換網路環境：嘗試切換 VPN 或手機熱點。
- 更新yt-dlp：避免版本過舊導致的存取問題。
- 使用**cookies登入**：YouTube可能阻擋疑似為機器人的請求，使用cookies登入能證明為真實使用者。
